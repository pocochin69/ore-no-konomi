俺の好み！で一発 // 謎の顔面測定器

構成:
- index.html
- style.css
- script.js
- target.png (今回添付された基準画像)

起動:
1. 同じフォルダに4ファイルを置く。
2. file:// 直開きより、ローカルHTTPサーバーを推奨。
3. Pythonがあればフォルダで `python -m http.server 8000`。
4. ブラウザで http://localhost:8000/ を開く。

AI:
MediaPipe Face MeshをCDNから読み込み、顔ランドマークをブラウザ内で取得します。
画像そのものはアプリからサーバーへアップロードしません。CDNからAIライブラリ/モデルを取得するため、初回起動時はインターネット接続が必要です。

スコア:
顔ランドマークを目間距離基準で正規化し、顔輪郭・目・鼻・口・比率・左右差を比較して俺の好み！で一発を0-90点にします。残り最大10点は、画像内の視認可能な身体領域に対するゲーム的な露出ボーナスです。

注意:
露出ボーナスは軽量なブラウザ内画像ヒューリスティックで、厳密な人体セグメンテーションではありません。肌色・照明・背景などで誤判定する可能性があります。
